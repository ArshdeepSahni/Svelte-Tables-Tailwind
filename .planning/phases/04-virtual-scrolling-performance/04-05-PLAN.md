Column virtualizer API (from @tanstack/svelte-virtual — same createVirtualizer function, horizontal mode):
```typescript
createVirtualizer<HTMLDivElement, HTMLTableCellElement>({
  count: resolvedColumns.length,
  getScrollElement: () => scrollEl!,
  estimateSize: () => 150,   // default column width in px
  horizontal: true,          // REQUIRED for column virtualization

```

VirtualItem (same type as row virtualizer):
```typescript
interface VirtualItem {
  key: string | number;
  index: number;   // → resolvedColumns[index]
  start: number;   // pixel offset from left
  end: number;
  size: number;    // 150 (estimateSize result)
  lane: number;
}
```

Column translateX pattern for th/td in horizontal virtualization:
Similar to row translateY, th and td elements are in normal document flow horizontally.
But table columns are sized by <col> elements or by content width — there's no horizontal flow offset
to compensate for (unlike rows where each row is block-level and stacked vertically).

For column virtualization in tables, the standard approach:
- DO NOT use translateX on individual th/td (breaks table column alignment)
- Instead: set explicit width and use position approach OR use CSS grid layout
- For semantic <table>, the safest approach is: render only the virtual columns (subset of th/td),
  each with explicit `style="width:{colItem.size}px; min-width:{colItem.size}px;"` and
  add empty <th>/<td> spacers for the non-rendered space left and right.

Spacer pattern for column virtualization in semantic table:
```svelte
<!-- In TableHeader row: -->
{#if isColumnVirtualizing}
  <!-- Left spacer th -->
  {#if columnVirtualItems[0]?.start > 0}
    <th style="width: {columnVirtualItems[0].start}px; padding: 0;" aria-hidden="true"></th>
  {/if}
  <!-- Virtual columns -->
  {#each columnVirtualItems as colItem}
    {@const col = resolvedColumns[colItem.index]}
    <th ... style="width:{colItem.size}px; min-width:{colItem.size}px;">...</th>
  {/each}
  <!-- Right spacer th -->
  {#if columnVirtualItems.at(-1)}
    {@const lastItem = columnVirtualItems.at(-1)!}
    {@const rightSpace = totalColumnSize - lastItem.end}
    {#if rightSpace > 0}
      <th style="width: {rightSpace}px; padding: 0;" aria-hidden="true"></th>
    {/if}
  {/if}
{:else}
  {#each columns as col (col.key)}..existing code...{/each}
{/if}
```

The same spacer pattern applies to TableBody td elements (replacing the {#each columns} loop).

totalColumnSize: same as totalVirtualSize but for columns — needs its own $state (or derived from columnVirtualItems).

Table.svelte needs to pass to both TableHeader and TableBody:
- columnVirtualItems: VirtualItem[]  (empty array = no column virtualization)
- totalColumnSize: number           (total width including non-rendered columns)
