CRITICAL PATTERN — translateY for semantic table rows (from RESEARCH.md):
The virtualizer's item.start is the absolute pixel position from the container top.
But <tr> elements in <tbody> are already positioned by normal document flow.
The nth tr naturally sits at n * rowHeight pixels from the tbody top.
So translateY needed = item.start - (natural position) = item.start - (index * item.size)

Example with overscan=5, scrolled to row 200:
  item[0]: { index: 195, start: 195*48=9360, size: 48 }  → translateY(9360 - 0*48) = 9360px
  item[1]: { index: 196, start: 196*48=9408, size: 48 }  → translateY(9408 - 1*48) = 9360px  ← same!
  Wait — that's correct because the tr is already 48px below the previous one in flow.
  net position = translateY + natural offset = 9360 + 0*48 = 9360  ✓
  net position = 9360 + 1*48 = 9408  ✓

Height spacer pattern (wraps <table>, NOT <tbody>):
  <div style="height: {totalVirtualSize}px; position: relative;">
    <table>...</table>
  </div>

The spacer div gives the scroll container its true scrollable height.
The table itself is position: relative (not absolute) inside the spacer.

    ```typescript
    $effect(() => {
      if (!scrollEl || !isVirtualizing) {
        virtualItems = [];
        totalVirtualSize = 0;
        return;
      }
      // Read row height from CSS variable at mount time
      const cssRowHeight = parseInt(
        getComputedStyle(scrollEl).getPropertyValue('--tc-row-height') || '48',
        10,
      );
      rowHeight = isNaN(cssRowHeight) ? 48 : cssRowHeight;

      const store = createVirtualizer<HTMLDivElement, HTMLTableRowElement>({
        count: sortedRows.length,
        getScrollElement: () => scrollEl!,
        estimateSize: () => rowHeight,
        overscan: 5,
      });

      const unsub = store.subscribe((v) => {
        virtualItems = v.getVirtualItems();
        totalVirtualSize = v.getTotalSize();
      });

      return unsub;
    });
    ```
